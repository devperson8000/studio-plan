# Studio Planner
Static site, no build step. Upload this folder to Vercel (Framework: Other).

## Realism pass
- Glare removed: no clearcoat, matte floors/walls, lower environment + bloom, softer tone mapping.
- Procedural textures (oak grain, weatherboard, plaster, grass), sky dome, shadowed ceiling light in walk mode,
  contact shadows under furniture, fairy lights, interior/exterior exposure adaptation.
- Walk mode: 1.62 m eye height, walking pace, head bob, frame-time clamp (no wall tunnelling).
